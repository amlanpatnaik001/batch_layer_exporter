Batch Layer Exporter

Batch export vector layers and attribute-defined subtypes to formats supported by the current QGIS/GDAL installation.

Quick start

  1. Copy the batch_layer_exporter folder into your active QGIS profile's python/plugins directory.
  2. Open Plugins → Manage and Install Plugins → Installed and enable Batch Layer Exporter.
  3. Open Plugins → Batch Layer Exporter, select vector layers, choose an export mode, CRS, formats, and output folder.
  4. Click Export Selected Layers. Review the live log and the optional manifest in the output folder.

QML style sidecars, QMD metadata sidecars, and the JSON manifest preserve useful QGIS-specific information where possible, but no external format can store every QGIS property.
